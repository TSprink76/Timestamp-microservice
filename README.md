Timestamp Microservice

A simple REST API that converts dates into Unix timestamps and returns human-readable UTC dates. It also supports converting Unix timestamps back into UTC date strings.

Features:
  Convert date strings into Unix timestamps.
  Convert Unix timestamps into UTC date strings.
  Return the current timestamp when no date is provided.
  Support Unix timestamps in milliseconds.
  Return JSON responses with consistent field names.
  Handle invalid dates with an appropriate error response.

Technologies Used:
  Node.js
  Express.js
  JavaScript
